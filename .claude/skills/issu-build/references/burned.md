# 데인 것

결과가 이상하거나 막히면 **먼저 여기를 본다.** 전부 실제로 겪은 것이고, 대부분 검사로
막아 뒀다.

## 로컬에서는 멀쩡한데 프로덕션에서만 깨진다

| 증상 | 원인 |
|---|---|
| 프로덕션만 **500** | 새 컬럼을 `hasColumn` 없이 읽었다. 마이그레이션이 수동이라 코드가 먼저 배포된다 |
| 프로덕션만 **404** | `server.js` 의 `APP_SURFACE` 허용목록에 경로를 안 넣었다. 로컬은 `all` 이라 다 열린다 |
| 화면은 되는데 값이 옛것 | 목업이 시드를 베껴 뒀다. 마이그레이션 SQL 을 직접 파야 한다 |

## 목업이 거짓말을 한 여섯 번

- 시드 값을 베껴 넣어 마이그레이션을 고쳐도 목업만 옛 값
- `sendError` 가 `unanswered` 목록을 안 내려보내 화면이 문항으로 이동 못 함
- `GET /deals` 가 `q`/`stage`/`mine` 을 무시 → 「내 딜」 버튼이 로컬에서 죽어 있었다
- `POST /deals` 가 041 기본값을 안 넣음
- `mockApplyReadiness` 가 `fix` 없는 문항으로 채점
- 솔루션 상세 404

**화면을 고쳤으면 목업도 고쳤는지 확인하고 넘어간다.**

## 목업 포트가 이미 떠 있다

`npm run mock` 이 `EADDRINUSE` 로 죽으면 **옛 프로세스로 확인하게 된다.** 실제로 이걸로
"고쳤는데 반영이 안 된다"를 한참 봤다. 띄우기 전에:

```
lsof -ti:4173 | xargs kill 2>/dev/null
```

로그(`/tmp/…`)에 `Mock UI server: http://127.0.0.1:4173` 이 찍혔는지 확인한다.

## 검사가 주석에 걸린 다섯 번

`change.operation` · `customer_contact` · `readiness_offering_weights` · `unit_price` ·
`ISSU 분류` — 전부 **주석이 그 단어를 설명하고 있을 뿐**인데 검사가 실패했다.
주석 줄을 걷어내고 실제 코드 참조 형태로 좁힌다. → `testing.md`

그리고 반대 방향도 있었다 — 어드민 커버리지 편집기가 **엔진이 못 읽는 모양으로
저장**하고 있었는데(솔루션을 저장할 때마다 판정 데이터가 조용히 파괴됐다), 검사 둘이
그 **깨진 동작을 확인**하고 있었다. 검사가 옛 동작을 굳히고 있으면 검사를 고친다.

## 마이그레이션

- **`2BP01`** — `drop table` 이 뷰 의존성에 막혔다. `cascade` 를 쓰지 말고 `drop view` 를
  **명시로 먼저** 적는다. 뭐가 딸려 지워지는지 모르는 채 지우면 안 된다
- **시드를 `apply-migrations.js` 에 넣었다** → 어드민에서 고친 값이 다음 적용 때
  초안으로 되돌아간다
- **`now()` 백필** → 전 행이 같은 시각이 된다(041). `gen_random_uuid()` 는 행마다 다르다(044)
- **지울 컬럼을 아직 읽는 코드** — 040 전에 세 곳이 나왔다. 그중 하나는
  `apply-migrations.js` 요약 쿼리라 **다음 적용이 통째로 실패**할 자리였다
- **콤마 조인 + 명시적 join** → `42P01`. 콤마가 둘일 때는 안 걸려서 더 헷갈린다

## 코드를 잘라낼 때

라우트를 지우려고 "다음 `app.<verb>(` 까지"를 잘랐더니 **옆 함수가 통째로 날아갔다**
(`requireReadinessScores`). `git checkout` 으로 되돌리고 중괄호 균형으로 다시 잘랐다.

정규식으로 코드를 치환할 때 **닫는 따옴표를 먹은** 적도 있다
(`app.get('/api/admin/recommendation-report, …`). 치환 후 `npm run check` 를 돌린다.

## 그 밖에

- **`git add -A` 가 엑셀 잠금 파일(`~$*`)을 커밋했다.** `.gitignore` 는 **이미 추적 중인
  파일에 안 먹는다** — 지우고 나서 무시 규칙을 넣어야 한다. `git status` 를 먼저 본다
- **`asArray`/`asObject` 를 그 파일에 없는데 갖다 썼다.** 파일마다 유틸이 다르다 —
  `(x || [])` 로 풀거나 그 파일의 것을 확인한다
- **네이티브 `title` 툴팁** — "마우스를 올려도 변화 없음"으로 읽힌다. `data-hint` + CSS
- **벤더 공시가 리서치** — 9곳 중 공식 공시가가 있는 곳은 4곳뿐이고, 서드파티 집계
  사이트는 공식 페이지와 **적극적으로 어긋난다.** 출처 없는 숫자를 쓰지 않는다
