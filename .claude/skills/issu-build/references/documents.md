# 산출물 — 고객용과 내부용

## 지우는 게 아니라 안 부른다

플래그 하나로 「고객용/내부용」을 갈라 쓰면 **언젠가 반드시 내부 문구가 고객 쪽으로
샌다.** 필터를 한 군데 빠뜨리는 순간이 온다.

그래서 고객용을 만드는 함수는 내부 재료를 **애초에 읽지 않는다.** `buildCustomerKit()`
(`hub.js`)이 선례 — `opinion`·`tech_note`·`talkTracks`·`mzc_sales`·`msp_status`·정체
시계·우리 단가·담당자 연락처를 **한 줄도 안 부른다.**

검사로 건다: 고객용 산출물에 금지 문자열이 **하나라도 있으면 실패.**

## 내부 전용 문구 7종

`lib/section-privacy.js` 의 `INTERNAL_BULLET_LABELS` 가 단일 규칙이다. 새로 목록을
만들지 않는다.

```
AI Tech 의견 · 마진 확보 전략 · SI 번들 마진 전략 · 딜 사이즈 극대화
MZC 시너지 번들링 · MZC 수익화 전략 · SI 번들 딜 구성
```

`solutions.sections` 본문에 섞여 있어 서버가 non-admin 응답에서 런타임으로도 걷어낸다
(`stripInternalSections`). 마이그레이션 적용 전에도 안 새게 하려는 것이다.

## 금액

- `price_is_placeholder` 가 켜져 있는 동안 고객 문서에 **숫자를 넣지 않는다** —
  「별도협의」만
- 벤더 공시가(`list_price`)는 고객에게 나가도 된다. **우리 단가(`unit_price`)는 안 된다**
- **Enterprise 가격과 최소 시트는 항상 「OpenAI 영업 협의사항」** 이다. 확정 금액으로
  쓰지 않는다
- 실단가가 확정되면 「더미 단가」 배너·「내부 참고용」 머리말을 **같이** 고친다

## 고객사 실명

**승인 없이 못 쓴다.** `case_studies.is_named` 가 false 면 서버가 응답에서
`customer_name` 을 **아예 뺀다**(`lib/case-match.js`). 화면에서 숨기는 방식이면 언젠가
어느 화면이 실수하는데, 잘라 내보내면 실수할 대상이 없다.

익명 표기(`customer_label`)는 승인 여부와 **무관하게 항상** 채운다 — 승인이 취소돼도
문서에 빈칸이 안 뜬다.

## 억지로 붙이지 않는다

매칭이 0건이면 **절 자체를 안 넣는다.** 고객이 "이게 우리랑 무슨 상관이죠"라고 물으면
그 뒤 문서 전체를 안 믿는다. 사례는 최대 2건 — 셋을 넘기면 사례집이 되고 아무도 안 읽는다.

## 내보내는 경로

`window.IssuReport` 의 `pdf` / `docx` / `markdown` 셋을 쓴다.

**서버는 PDF 를 만들지 않는다.** CJK 폰트 embed 는 용량·라이선스 판단이 필요한 별건이라
(`report.js` 머리말에 이유가 있다) 서버가 쓸 수 있는 것은 마크다운 · `toHtml()`+`PRINT_CSS`
HTML · `buildDocx()` 바이트 셋이고, PDF 는 사용자가 화면에서 저장한다.

## 「모르는 것」을 숨기지 않는다

미확인 항목은 문서에서 지우는 게 아니라 **어디가 비었는지 보이게** 한다. 다만 고객
문서에 "우리가 아직 모르는 것" 목록을 그대로 보내지는 않는다 — `collectOpenItems()`
결과는 영업에게 토스트로 알리고, 문서에는 「함께 확인이 필요한 항목이 있습니다」로 나간다.

내부 산출물은 반대다. **빈칸을 그대로 드러내고** 누가 무엇을 물어야 하는지 적는다.
